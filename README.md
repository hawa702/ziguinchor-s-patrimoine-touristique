# Ziguinchor Tourist Heritage

##  Overview

The Ziguinchor Tourist Heritage Software is a web application developed to inventory, manage, and promote the cultural, historical, and natural heritage of the Ziguinchor region (Casamance, Senegal).

It provides an easy-to-use interface for managing tourist sites, categories, and related information.

##  Features

- Manage tourist heritage sites
- Add, edit, and delete tourist information
- Upload and manage images
- Browse and search tourist sites
- Responsive and user-friendly interface

##  Technologies Used

- Java
- Spring Boot
- Thymeleaf
- Spring Data JPA
- H2 Database
- HTML5
- CSS3
- Bootstrap
- JavaScript

##  Installation

1. Clone the repository

```bash
git clone https://github.com/hawa702/ziguinchor-s-patrimoine-touristique.git
```

2. Open the project in IntelliJ IDEA.

3. Run the Spring Boot application.

4. Open your browser and visit:

```
http://localhost:8080
```
